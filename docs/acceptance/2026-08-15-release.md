# Graft 0.1.0 release acceptance

Date: 2026-08-15 (Asia/Shanghai)

## Scope

This build targets macOS 26 or newer on Apple silicon only. It intentionally uses
the installed system Git for repository semantics, credentials, SSH, signing,
hooks, and network operations. It does not include x86_64 compatibility or
telemetry.

## Verified workflows

- open and automatically refresh a repository through FSEvents invalidation;
- browse a real parent-aware, virtualized, paged commit graph and commit patches;
- search history, inspect merge commits against their first parent, and copy OIDs;
- include/exclude whole files and individual diff hunks, commit, amend, and commit
  then push;
- fetch, fast-forward pull, push, switch/create branches, and create tags/remotes;
- merge, cherry-pick, revert, soft/mixed/hard reset, continue, or abort operations;
- plan interactive rebase actions (pick, reword, edit, squash, fixup, drop), reorder
  commits, execute through system Git, and resume paused operations;
- inspect three-way conflict content, select a side or edit the result, and mark it
  resolved;
- list, create, open in a separate window, lock, unlock, remove, and prune Git
  worktrees.

## Automated gates

- `npm run check`: passed (Vue type/build, 3 Vitest files / 6 tests, 6 Rust tests);
- strict Rust lint: `cargo clippy --all-targets -- -D warnings`: passed;
- full-history ignored benchmark: passed against 524,408 commits;
- dependency audit: `npm audit`: 0 known vulnerabilities;
- frontend release payload: 146.51 kB JavaScript (50.19 kB gzip) and 30.30 kB CSS
  (6.10 kB gzip).

## Packaging and trust

The `.app` and `.dmg` are thin arm64 artifacts. The local release uses an ad-hoc
hardened-runtime signature and is verified with `codesign --verify --deep
--strict`. Developer ID signing and Apple notarization require the owner's Apple
Developer credentials and are therefore the only distribution step not performed
by this local build.
